# 🍫 BBR Card Studio (빼빼로데이) — 동일 프로그램 제작 · 개발 가이드

이 문서는 **BBR Card Studio**(`/home/jeonsr/바탕화면/Project/BBR`)를 기반으로 또 다른 기념일 온라인 카드 프로그램(예: 연하장, 발렌타인데이, 어버이날, 청첩장, 감사인사 등)을 동일 아키텍처로 제작할 때 사용하는 개발 가이드입니다.

## 2. 재사용 모듈 vs 신규 제작 시 커스터마이징 대상

기존 `X-mas`에서 `BBR`을 분리 구축할 때 검증된 **그대로 재사용 가능한 모듈**과 **테마별 교체 대상**은 다음과 같습니다.

### 그대로 재사용 가능한 핵심 코어
- DB/모드/보안: `src/lib/prisma.ts`, `src/lib/mode.ts`, `src/lib/privacy.ts`, `src/lib/network.ts`, `src/lib/solapi.ts`
- API 라우트 코어: `src/app/api/cards/[slug]/route.ts`, `src/app/api/cards/[slug]/open/route.ts`, `src/app/api/config/status/route.ts`, `src/app/api/manage/[manageToken]/route.ts`, `src/app/api/settings/route.ts`
- 인프라/빌드: `scripts/prepare-prisma.mjs`, `next.config.ts`, `tsconfig.test.json`, `eslint.config.mjs`

### 새 기념일 프로그램 제작 시 교체할 영역
1. **테마 · 프리셋 · BGM (`src/lib/templates.ts`, `src/lib/music.ts`)**:
   - `BBR`은 `sweet-choco`, `strawberry-pink`, `almond-gold`, `midnight-star` 4종 테마와 `love-greeting`, `sweet-gift`, `twinkle-star` 오르골 3종 사용
2. **시각 모티프 & 파티클 (`src/components/CardMotif.tsx`, `src/components/SweetCanvas.tsx`)**:
   - SVG 카드 엠블럼 및 배경 Canvas 파티클(하트·별·반짝임 등) 커스터마이징
3. **샘플 이미지 (`public/samples/` & `src/lib/samples.ts`)**:
   - `sample-choco.png`, `sample-strawberry.png`, `sample-almond.png`, `sample-gift.png`를 새 기념일 일러스트 4종으로 교체
4. **이메일 · 카톡 · SMS 문구 (`src/lib/email.ts`, `src/lib/share.ts`, `src/app/api/manage/[manageToken]/deliveries/route.ts`)**:
   - `11.11 HAPPY PEPERO DAY` 배지, `🍫` 이모지, `[빼빼로데이 카드]` 말머리 등 변경
   - 카카오톡 `Kakao.Share.sendDefault` 호출 시 반드시 `imageWidth: 1200`, `imageHeight: 600` 및 이미지 URL 캐시 버스터(`?v=...`) 포함
5. **카카오톡 잘림 방지 OG 이미지 (`src/app/c/[slug]/opengraph-image.tsx`)**:
   - `size = { width: 1200, height: 600 }` (`2:1` 카카오 피드 표준)
   - 카톡 미리보기가 `4:3`이나 `1:1` 정사각형으로 중앙 크롭할 때 글자가 잘리지 않도록 **중앙 `520px` 폭의 안전 영역(Safe Zone) 패널** 안에 제목/배지/발신자를 배치하고 `wordBreak: "keep-all"` 적용

## 3. 다중 앱 동시 운영 시 충돌 방지 6대 원칙

1. **전용 포트 할당**: `X-mas`(`3000`)와 겹치지 않도록 `3011` (`package.json`, `launch.sh`) 사용
2. **임시 런타임 파일 접두사 분리**: `/tmp/bbr-card-studio.{port,pid,buildid,log}`
3. **로컬 비밀 설정 파일 분리**: `src/lib/settings.ts` → `.bbr-settings.local.json` (`0600`, `.gitignore` 제외)
4. **DB 분리**: 로컬 SQLite 또는 전용 Neon PostgreSQL 프로젝트(`DATABASE_URL`) 사용
5. **GitHub · Vercel 별도 생성**: 전용 저장소(`https://github.com/jeonsr8710/BBR`) 및 Vercel 프로젝트(`https://bbr-tawny.vercel.app`, `PUBLIC_VIEWER_ONLY="true"`) 연결
6. **카카오 앱 별도 생성 및 2곳 도메인 등록**:
   - **앱 설정 → 플랫폼 키 → JavaScript 키 → `JavaScript SDK 도메인`**: `http://localhost:3011`, `https://bbr-tawny.vercel.app`
   - **제품 링크 관리 → `웹 도메인`**: `https://bbr-tawny.vercel.app` *(누락 시 `온라인카드 열어보기` 버튼이 사라지거나 다른 앱 기본 도메인으로 이동함)*

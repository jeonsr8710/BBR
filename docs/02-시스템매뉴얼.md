## 3. 주요 API 동작 요약

- **`GET /api/cards`**: 최근 카드 최대 50건 반환. 각 카드의 `deliveries`에서 중복 제거한 `recipientSummary`(`미발송` / `소중한 OO` / `OOO 외 N명`)와 `totalOpens`, `replyCount`를 계산해 반환합니다. (`PUBLIC_VIEWER_ONLY=true` 시 `403` 차단)
- **`POST /api/manage/[manageToken]/deliveries`**:
  - `EMAIL`: 수신자별 10자리 토큰(`?d=`) 생성 후 SMTP/Resend 발송 (미설정 시 `PREVIEW` HTML 생성)
  - `KAKAO`: `https://bbr-tawny.vercel.app/c/[slug]?d=[token]` 링크와 `.../opengraph-image?v=2` (`1200×600`) 포함 `kakaoPayload` + QR 반환
  - `SMS`: Solapi API 직접 발송 또는 `/sms-launch?d=[token]` QR 생성
  - `LINK`: 개인화 링크 및 QR 즉시 발급
- **`GET /c/[slug]/opengraph-image`**: `1200×600` (`2:1`) PNG 생성. 중앙 `520px` 안전 영역 카드에 테마 색상, 빼빼로 바 그래픽, `11.11 HAPPY PEPERO DAY` 배지, 제목, 보내는 분 이름을 렌더링합니다.

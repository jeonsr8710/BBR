# 🍫 BBR Card Studio — 사용법 매뉴얼

이 문서는 **빼빼로데이 온라인 카드**를 제작하고 **카카오톡 · 이메일 · SMS 문자 · 개인화 링크**로 발송하며 열람과 답장을 관리하는 실사용 안내서입니다.

---

## 1. 프로그램 시작하기

1. 바탕화면의 금빛 테두리 **`빼빼로데이 카드`** (`11·11`) 아이콘을 더블클릭합니다.
2. 브라우저에서 **`http://localhost:3011`** 화면이 자동으로 열립니다. *(기존 크리스마스 카드 `3000` 포트와 별도로 동시 실행 가능)*
3. 상단 **[발송 설정]** 에서 공유 링크·카카오톡·이메일·SMS 정보를, **[사용 매뉴얼]** 에서 요약 가이드를 확인할 수 있습니다.

---

## 2. 카드 만들기

1. **디자인 테마 선택 (4종)**:
   - `스윗 초코 빼빼로` / `딸기 크런치 로즈` / `아몬드 골드 레터` / `달빛 기프트 박스`
2. **문구 작성**:
   - `연인 · 짝꿍`, `친구 · 동료`, `가족 · 감사` 추천 인사말 버튼으로 기본 문구를 채운 뒤 내 이름(보내는 분), 제목, 메시지를 수정합니다.
3. **이미지 첨부 (선택)**:
   - 기본 빼빼로 일러스트 4종(초코·딸기·아몬드·기프트박스) 중 고르거나 내 PC 사진(1MB 이하 권장)을 첨부합니다.
4. **배경음악 선택 (Web Audio 오르골)**:
   - `사랑의 인사 (오르골)`, `해피 기프트 멜로디`, `반짝반짝 작은 별`, `배경음악 없음` 중 선택합니다.
5. **실시간 미리보기 확인 후 저장**:
   - 우측 미리보기에서 **봉투 / 열린 카드**를 전환해 본 뒤 **`카드 저장하고 보내기`** 버튼을 누릅니다.

---

## 3. 하단 `만든 카드 목록` 사용법

- 에디터 화면 맨 아래 **`만든 카드 목록`** 에 DB에 저장된 카드가 자동 표시됩니다.
- 각 카드 항목은 **`보내는 분 · 받는 분 · 열람 N · 답장 N`** 형식으로 한눈에 확인할 수 있습니다. *(예: `전성열 · 소중한 재호 · 열람 4 · 답장 1`)*
- 카드를 클릭하면 발송 관리 화면으로 이동하며, 왼쪽 체크박스로 여러 카드를 선택해 **`선택 삭제`** 하거나 우측 휴지통 아이콘으로 개별 삭제할 수 있습니다.

---

## 4. 채널별 발송 방법 (`/manage/[manageToken]`)

### ① 카카오톡 공유
1. **받는 분 이름**을 입력합니다. (카드 봉투에 `To. OOO님`으로 표시됨)
2. **`카카오톡으로 공유하기`** 버튼을 누르면 카카오 친구/채팅방 선택 창이 열립니다.
   - 썸네일 이미지(`1200×600`)와 **`온라인카드 열어보기`** 버튼이 함께 전송됩니다.
   - *(만약 키가 없어도 **`카톡 공유 문구 & QR 생성`** 으로 문구와 개인화 링크를 복사해 바로 보낼 수 있습니다.)*

### ② 이메일 발송
1. 최초 1회 상단 **[발송 설정] → [이메일]** 에 Gmail(`앱 비밀번호 16자리`), 네이버 메일(SMTP), 또는 Resend API 키를 저장합니다.
2. 수신자 이름과 이메일을 추가(최대 30명)해 발송하면, 카드 이미지와 **`✨ 온라인카드 열어보기`** 버튼이 들어간 HTML 메일이 전송됩니다.

### ③ SMS 문자 발송
- **무료 스마트폰 QR 방식**: **`스마트폰 QR · 문자 앱 링크 생성 (무료)`** 클릭 후 휴대폰 카메라로 QR을 스캔하면, 폰 기본 문자 앱에 받는 번호·인사말·카드 링크가 미리 입력된 상태로 열립니다.
- **PC 직접 발송 (Solapi API)**: `[발송 설정] → [SMS 문자]`에 Solapi API 키와 사전 등록된 발신번호를 저장하면 PC에서 바로 SMS/LMS를 보낼 수 있습니다.

### ④ 개인화 링크 복사
- 받는 분 이름별 전용 링크(`/c/[slug]?d=[token]`)와 QR 코드를 만들어 원하는 메신저에 직접 붙여넣을 수 있습니다.

---

## 5. 수신자 카드 열람 & 답장 흐름

1. 지인이 카톡·메일·문자의 링크(`https://bbr-tawny.vercel.app/c/...`)를 누르면 내 PC가 꺼져 있어도 24시간 카드가 열립니다.
2. 지인이 봉투를 클릭해 카드를 열면 배경음악·하트 파티클과 함께 카드가 펼쳐지고, 발송 관리 화면의 **열람 횟수**가 자동으로 증가합니다.
3. 지인이 하단에서 이모지(`🍫` 등)와 답장을 남기면 관리 화면 **받은 답장**과 첫 화면 하단 카드 목록의 **답장 수**에 즉시 반영됩니다.

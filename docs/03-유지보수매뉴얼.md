## 3. 자주 발생하는 장애 & 해결 방법

### Q1. 카카오톡 공유 시 `온라인카드 열어보기` 버튼이 사라지거나 다른 사이트로 열림
- **원인**: 카카오 디벨로퍼스에서 `JavaScript SDK 도메인`만 등록하고 **`제품 링크 관리 → 웹 도메인`** 등록을 빠뜨렸거나, 다른 앱 키가 들어있음.
- **해결**:
  1. 카카오 디벨로퍼스 → **`빼빼로데이` 앱** 선택
  2. **플랫폼 키 → JavaScript SDK 도메인**: `http://localhost:3011`, `https://bbr-tawny.vercel.app` 등록 확인
  3. **제품 링크 관리 → 웹 도메인**: `https://bbr-tawny.vercel.app` 등록 및 기본 웹 도메인 설정 확인
  4. `BBR` **[발송 설정] → [카카오톡]** 키가 해당 앱의 JavaScript 키인지 확인 후 브라우저 **`F5` 새로고침**

### Q2. 카카오톡 미리보기 이미지가 예전 모양이거나 좌우가 잘림
- **원인**: 카카오 서버가 이전 이미지 URL을 캐시하고 있음.
- **해결**: [deliveries/route.ts](file:///home/jeonsr/바탕화면/Project/BBR/src/app/api/manage/%5BmanageToken%5D/deliveries/route.ts#L260)의 `?v=2` 버전 숫자를 올리거나, 카카오 디벨로퍼스 **도구 → 공유 디버거**에서 해당 URL 캐시를 초기화합니다.

### Q3. 로컬에서 만든 카드가 `https://bbr-tawny.vercel.app/c/...`에서 404로 나옴
- **원인**: 로컬 `.env`의 `DATABASE_URL`이 SQLite(`file:./dev.db`)로 바뀌어 있거나, Vercel 환경변수 `DATABASE_URL`과 서로 다른 DB를 바라봄.
- **해결**: 로컬 `.env`와 Vercel Environment Variables의 `DATABASE_URL`이 동일한 Neon PostgreSQL 프로젝트 주소인지 확인 후 `npm run db:push` 실행.

### Q4. Vercel 페이지에서 카드 만들기/목록이 막혀 있음(`403`)
- **정상 동작**: Vercel 배포 환경에서는 `PUBLIC_VIEWER_ONLY="true"`로 인해 열람 전용(`BBR Card Viewer`)으로 동작하도록 의도된 보안 설계입니다. 카드 제작·발송·목록 관리는 로컬 PC(`http://localhost:3011`)에서 사용합니다.
